Overview

This project explores early file-based data management systems by manually processing a CSV of country and city data using Python. The exercise demonstrates challenges like data dependence and structural dependence, which modern Database Management Systems (DBMS) have resolved.

We implemented queries such as:

	•	Countries ending with “a”
  
	•	Cities with the highest populations
  
	•	Countries with the largest landmass

⸻

Features
	•	Read and parse large CSV files without external libraries
  
	•	Filter, sort, and aggregate data using Python dictionaries
  
	•	Handle duplicates, missing values, and invalid entries
  
	•	Output answers to 8 predefined queries in a text file

⸻

Installation & Running

	1.	Clone the repo:

git clone https://github.com/your-username/Databases-FileSystem-Assignment.git

	2.	Navigate to src folder:

cd Databases-FileSystem-Assignment/src

	3.	Run the script:

python file_system_analysis.py

	4.	Check the answers in output/answers.txt.
